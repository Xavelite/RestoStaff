# RestoStaff v175 — Export Center

Adds an owner Export Center and focused print/CSV actions.

## Exports included

- Weekly actual timesheet CSV and print report
- Payroll/accountant CSV and print preview
- Planning CSV and print report
- Inventory stock CSV and print report
- Inventory movements CSV and print report
- Existing JSON backup export retained

## Scope

Exports use the current one-row JSON app state. Belgian payroll calculation and provider-specific formats are intentionally not included yet.
