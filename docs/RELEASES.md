# Releases

## Versioning

Production deployments use a short product release label:

- Git tag and deployment label: `v1.00`, `v1.01`, `v1.02`, and so on.
- Package SemVer: `1.0.0`, `1.0.1`, `1.0.2`, and so on.
- `PUBLIC_APP_RELEASE` must match the Git tag so monitoring and pilot feedback
  identify the deployed version.

Increment the final two-digit release number for every production deployment.
